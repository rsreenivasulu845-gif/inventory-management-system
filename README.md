# Inventory Management System

A desktop inventory and stock management dashboard built using Python, CustomTkinter, and SQLite.

## Features

- **CRUD Operations**: Add, update, view, and delete stock records.
- **Dynamic Serial Numbers**: Continuous numbering (`S.No`) independent of deleted records.
- **Low Stock Alerts**: Automatic visual flags and counter for low-inventory items.
- **Search & Filter**: Real-time filtering by product name and category.
- **CSV Export**: One-click inventory report downloads.
